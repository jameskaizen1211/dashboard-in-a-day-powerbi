## How to Open

**Prerequisite:** Power BI Desktop

1. Download `DashboardInADay.pbix` from this repository.
2. Open the file in Power BI Desktop.
3. Review the existing report pages as saved — a refresh is not required to inspect the report.

**Refresh note:** Refreshing the model may require the original course datasets and corrected data-source paths. Without those files and path updates, refresh can fail even though the saved report remains viewable.
