## Overview

This repository documents my DIAD coursework and the resulting Power BI model/report:

- **Desktop labs:** Power Query data prep, relationship modeling, DAX measures, and report page design
- **Service labs:** Publish to the Power BI Service, build a dashboard, and practice sharing/collaboration workflows
- **Deliverable focus:** `MyFirstPowerBIModel.pbix` as the primary Desktop artifact

Built as portfolio evidence for a Power BI Business Intelligence Analyst & Developer role.

## How to Open

### Prerequisites
- Power BI Desktop (current version)
- Power BI Service account (for republishing / dashboard labs)
- Optional: import `Eclipse_NavyTeal_Portfolio.json` via **View → Themes → Browse for themes**

### Steps
1. Clone this repo (or download the release files).
2. Open `MyFirstPowerBIModel.pbix` in Power BI Desktop.
3. If prompted for data source credentials, sign in per the DIAD lab instructions *(TODO: confirm which connectors the file still uses)*.
4. **Refresh** the model, then review report pages.
5. Apply the custom theme JSON if needed after refresh.
6. To repeat Service labs: **Publish** to a workspace, pin visuals to a dashboard, and configure sharing as in the Microsoft path.

> **Note:** Course solution files (e.g., Lab 5) remain in local student materials and are not redistributed here.
